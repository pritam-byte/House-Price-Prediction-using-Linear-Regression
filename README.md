# House-Price-Prediction-using-Linear-Regression
ml_project
🏠 House Price Prediction using Linear Regression
📌 Project Overview

This project builds a Supervised Machine Learning regression model to predict residential house prices based on property features such as location, construction details, and house condition.
The goal is to help real estate companies automate the house price estimation process using historical property data.

🎯 Problem Statement

A real estate company wants to automate the process of estimating the market price of houses.
Using historical property data, a Machine Learning model is developed to predict the selling price of a house based on its physical characteristics and location-related features.

📊 Dataset Description

The dataset contains multiple features describing residential houses.

Feature	Description
Id	Unique identification number for each house
MSSubClass	Type of dwelling involved in the sale
MSZoning	General zoning classification
LotArea	Lot size in square feet
LotConfig	Lot configuration (Corner, Cul-de-sac, etc.)
BldgType	Type of dwelling (1Fam, Duplex, etc.)
OverallCond	Overall condition rating (1–10 scale)
YearBuilt	Year the house was originally built
YearRemodAdd	Year when remodeling or additions were made
Exterior1st	Exterior covering on house
BsmtFinSF2	Finished square feet of basement
TotalBsmtSF	Total basement area
SalePrice	Final selling price (Target Variable)
